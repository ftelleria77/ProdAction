# iso/docs — Documentación e investigación

## Subdirectorios

| Carpeta | Contenido |
| --- | --- |
| `memory/` | Inventario de parámetros ISO observados, bloques reutilizables y bitácora de evidencia. |
| `experiments/` | Tablas de estado derivadas de estudios controlados con fixtures. Una por familia de operación. |
| `contracts/` | Contratos de formato para el ISO intermedio (XISO) y la interfaz del convertidor. |

## Convención de nombres

- `memory/iso_parameters.md` — memoria principal, se actualiza con cada nuevo hallazgo.
- `experiments/NNN_nombre.md` — resultado de un estudio numerado; no se modifica retroactivamente.
- `contracts/NNN_nombre.md` — contrato de interfaz; se versiona cuando cambia el formato.
