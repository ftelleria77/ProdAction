# iso/synthesis — Módulos productivos

Código de conversión PGMX→ISO listo para producción. Solo contiene reglas
validadas contra ISO Maestro real.

## Criterio de inclusión

Un módulo entra aquí cuando:

1. La regla fue observada y documentada en `iso/docs/experiments/`.
2. Existe un test de regresión en `tests/`.
3. El comportamiento no depende de inspección manual de cada caso.

## Estado inicial

Sin módulos productivos aún. El primer módulo se incorporará una vez
completado el análisis del lote N001.
